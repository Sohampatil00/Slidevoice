# Changelog

## 0.1.1 — Desktop development build

- Shared SlideVoice branding for macOS app bundles, Windows EXE/setup, shortcuts, and favicon.
- Gemini-only desktop key settings and LuxTTS narration controls.
- Presentation mode with native fullscreen, keyboard navigation, and narration-driven slide advance.
- Persistent desktop storage, automatic LuxTTS runtime setup, and owned-worker cleanup on native Quit.
- Native Mac development build verified locally; Windows installer and portable ZIP pipeline prepared for native CI.

## 0.1.0 — Initial GitHub publication

- Local browser studio for PDF, PPTX, and image presentations.
- Per-slide narration editing and full-script import with preview/apply.
- Optional Claude drafting and content-based script matching.
- Optional local Indic-MIO voice cloning, macOS preview speech, and uploaded recordings.
- Narration caching, bounded chunk retries, progress tracking, and per-project edit locks.
- Audio-measured slide timing and 1080p/720p MP4 export with timestamps.
- Setup, configuration, architecture, privacy, contribution, and security documentation.
- Automated workflow, provider protocol, script-import, and media integration tests.

This is a single-user local MVP. Public hosting, authentication, durable queues, cancellation, and collaboration are not included.
