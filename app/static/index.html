YOUR STUDIO, CONNECTED
A quick setup.
Start with the demo or upload a PDF. You can paste scripts and upload recordings without any paid services.
Indic-MIO & your own voice
  1. Run indic-mio.command in the SlideVoice folder. First launch downloads model weights and optional Python packages.
  2. Wait for the model server to finish loading. Keep its terminal open.
  3. Import slides, select Indic-MIO, confirm voice permission, and upload 3–20 seconds of your own speech.
  4. Generate one slide’s narration to check accent, pronunciation, and similarity before generating the full deck.
  5. Optionally add ANTHROPIC_API_KEY in .env for Claude scripts. Restart the studio after changing configuration.
Local Indic-MIO requires no speech API key. Scripts and reference audio go to the configured model server, defaulting to your own computer. A remote server receives both. Claude script generation still sends slide content to Anthropic and may incur charges. Keys stay on the backend.
Set INDIC_MIO_BASE_URL to use an existing MioTTS-Inference-compatible server running SPRINGLab/Indic-Mio. Static slides do not preserve PowerPoint animations or videos.
